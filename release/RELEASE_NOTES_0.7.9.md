## DisfigureTranslationMod 0.7.9

Compatibility update for Disfigure 1.0 using BepInEx 6 IL2CPP.

- Rebuilt against Disfigure 1.0.
- Refreshed all nine shipped language catalogs for the current game text.
- Updated runtime translation handling for the current user interface.
- Existing language selection and controls remain unchanged.

### Downloads

- **All-in-one Windows x64:** includes the official unmodified BepInEx 6 IL2CPP loader. Extract beside `Disfigure.exe` and launch the game.
- **Mod only:** for players who already have BepInEx 6 IL2CPP installed. Extract into the game directory.

Press F8 in game to select a language, F5 to reload translations, or F4 to force a rescan.

This release targets Disfigure 1.0. Not every screen and language combination has been exhaustively reviewed.
