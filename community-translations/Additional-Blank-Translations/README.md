# Additional blank translation files

These files cover text outside the game translation catalog:

- [Documentation](Documentation) — the main README and community translation instructions.
- [Mod Manager](Mod-Manager) — buttons, labels, status messages, dialogs, errors, and catalog descriptions shown by the desktop manager.
- [Sandbox Mod](Sandbox-Mod) — only text created by Sandbox Mode itself, including tab labels, buttons, status messages, timer controls, and enemy-spawn controls.

Sandbox files intentionally exclude upgrade, perk, mutation, weapon, and enemy names or descriptions. Those already come from Disfigure and are handled by the Translation Mod.

Choose the file named with the full language name and fill in only its blank values.
